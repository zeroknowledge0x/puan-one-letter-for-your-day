One Letter for Your Day: send exactly one letter, A to Z, standing for the word that describes your day. This entry sends Q.

The output file holds exactly one byte, `Q`, with no newline — the gate reads 1 to 1 characters. The letter stands for a quirky, quitting sort of day: vivid, funny and true.

## Run it

```sh
node --experimental-strip-types main.ts
```
